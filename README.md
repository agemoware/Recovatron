# Recovatron

Recovatron is a desktop tool for recovering files from USB drives and SD cards.

## Features

- Read-only scan (your data is never modified)
- Preview files before recovery
- Simple and fast workflow
- Works fully offline (no cloud upload)

## Download

👉 https://github.com/agemoware/recovatron/releases/latest

## How it works

1. Connect your USB drive or SD card  
2. Start scan  
3. Preview found files  
4. Recover what you need  

## Notes

- The application runs locally and does not upload your data anywhere  
- If Windows shows a warning, it’s because the app is new
